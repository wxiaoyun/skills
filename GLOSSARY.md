# Agent Knowledge

Shared notes that agents read and write across sessions, and the upkeep that keeps them small and findable.

## Notes

**Note**:
A markdown file in `~/tk` holding lasting understanding about one tool, repo, service or workspace.
_Avoid_: doc, memory, entry

**Record**:
A note capturing one investigation or incident, true for its date only.
_Avoid_: history note, log

**Vote**:
A dated verdict that a note's evidence still holds or no longer holds.
_Avoid_: rating, score

## Sleep

**Sleep**:
A pass over the notes that consolidates them, the counterpart to writing them during a session.
_Avoid_: cleanup, gc, compaction

**Merge**:
Folding overlapping notes into one surviving note.
_Avoid_: dedup, combine

**Forget**:
Removing a note from the live set so it survives only in git history.
_Avoid_: archive, delete, prune

**Compress**:
Cutting a note down to its live facts while keeping every piece of evidence.
_Avoid_: trim, summarize

**Distill**:
Lifting the lasting facts out of a record into regular notes.
_Avoid_: extract, promote

**Strengthen**:
Making a heavily read note cheaper to find and to read.
_Avoid_: boost, reinforce
